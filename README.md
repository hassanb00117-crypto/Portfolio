## Publish with GitHub Pages

### Recommended: create a dedicated profile website repository
1. Sign in to GitHub as `hassanb00117-crypto`.
2. Create a **public** repository named exactly `hassanb00117-crypto.github.io`.
3. Extract this ZIP on your computer.
4. Upload **all contents inside the `hassan-bashir-portfolio` folder**, including the `assets` folder, to the repository root. The `index.html` file must be at the root, not inside another nested folder.
5. Commit the files to the `main` branch.
6. Open **Settings → Pages**. If GitHub has not enabled Pages automatically, choose **Deploy from a branch**, select `main` and `/(root)`, then Save.
7. After deployment finishes, visit **https://hassanb00117-crypto.github.io**.

### Alternative: use an existing repository
You can upload the same files to an existing public repository and enable Pages in **Settings → Pages**. A project repository normally gets a URL in the form `https://hassanb00117-crypto.github.io/REPOSITORY-NAME/`.
